# Public data dictionary

## Articles.csv
Synthetic main table representing article-level analytical records.

## Architectures.csv
Synthetic many-to-one mapping between article identifiers and model architecture categories.

## Metrics.csv
Synthetic mapping between article identifiers and evaluation metrics.

## Limitations.csv
Synthetic mapping between article identifiers and methodological limitation themes.

## Interpretations.csv
Synthetic interpretative text used only to preserve the dashboard's insight section.

## Quality.csv
Synthetic aggregate values used to demonstrate methodological quality visualizations.

`Article ID` is an artificial identifier used only to preserve relationships across the public datasets.
