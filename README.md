# AI & CRISPR Research Dashboard

Public, sanitized portfolio edition of a Power BI dashboard developed in the context of an undergraduate research project involving Artificial Intelligence applied to CRISPR technologies.

> **Important:** all data available in this repository are synthetic and were created exclusively for portfolio demonstration. They do not represent the results, sample, classifications, or conclusions of the original research.

## Project overview

The dashboard was designed to organize and visualize information extracted from scientific literature on the use of Artificial Intelligence in CRISPR-related applications.

The public edition preserves the analytical structure of the original project while replacing research data with synthetic records.

## Dashboard structure

### 1. Overview
High-level indicators, publication trends, AI approaches, CRISPR systems and task categories.

### 2. Safety & Validation
Experimental validation, code availability, target components, methodological limitations and reproducibility.

### 3. Models & Metrics
Model architectures, reported evaluation metrics, input modalities and a synthetic article catalog.

### 4. Quality & Insights
Methodological quality dimensions, bottlenecks and synthetic interpretative insights.

## Data privacy and sanitization

The original research dataset is not included in this repository.

The portfolio edition replaces:
- article references and identifiers;
- research classifications;
- extracted study-level information;
- methodological results;
- interpretative conclusions;
- quality scores and aggregate findings.

Synthetic records preserve the dashboard structure and relationships without exposing unpublished research information.

## Disclaimer

This repository is intended exclusively to demonstrate data analysis, dashboard development and data-visualization skills. The synthetic values shown here should not be interpreted as scientific findings.
