# Sanitization notes

This repository contains a public portfolio edition of a dashboard originally developed in a research context.

## Removed or replaced

The following information from the original research was not published:

- real article references and identifiers;
- article-level classifications;
- unpublished methodological results;
- original quality scores;
- research-group interpretations;
- study-specific model and tool information where it could reconstruct the review sample.

## Preserved

The public edition preserves:

- report page structure;
- visual design;
- data-model logic;
- relationships between tables;
- DAX measures;
- analytical workflow;
- types of KPIs and visualizations.

All public records are synthetic.
